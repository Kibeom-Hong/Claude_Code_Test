## 0. 한 줄 요약 — 이 강의가 전달해야 할 메시지

> **"VLA = 인터넷으로 세상을 배운 VLM(눈+언어)에, 로봇의 '손'(Action)을 붙인 모델.
> 핵심 난제는 '행동을 어떻게 표현/출력하느냐'와 '로봇 데이터가 부족하다'는 것이고,
> RT-2 → OpenVLA → π0 → π0.5 로 이어지는 흐름이 이 두 문제를 풀어온 역사다."**

청중이 강의실을 나갈 때 아래 3가지를 말할 수 있으면 성공입니다.

1. **VLA가 무엇인지** (입력: 이미지 + 언어 + 로봇 상태 → 출력: 로봇 행동) 한 문장으로 설명할 수 있다.
2. **행동을 출력하는 4가지 방식** (이산 토큰 / 연속 회귀 / 디퓨전·플로우 매칭 / 압축 토큰 FAST) 의 차이를 안다.
3. **대표 논문 계보** (RT-1 → RT-2 → OXE → Octo → OpenVLA → π0 → π0.5 → 이중 시스템(GR00T·Helix·Gemini Robotics) → RL로 스스로 개선(π*0.6)) 를 순서대로 설명할 수 있다.

## 4. 강의 운영 팁

1. **"질문 → 답" 구조로 끌고 가기.** 각 Part를 질문으로 시작하면 집중도가 올라갑니다.
   - Part 1: "LLM은 시를 쓰는데, 왜 로봇은 아직 빨래를 못 갤까?"
   - Part 2: "언어 모델은 '단어'를 출력하는데, 로봇 팔의 움직임은 어떻게 출력하지?"
   - Part 3: "그럼 실제로 사람들은 이 문제를 어떻게 풀어왔을까?"
   - Part 4: "그래서 이제 다 된 걸까?"
2. **색깔 약속을 처음에 말해두기.** 슬라이드 전체에서 **청록 = Vision, 보라 = Language, 주황 = Action** 으로 통일했습니다. 첫 VLA 정의 슬라이드에서 "앞으로 이 색이 나오면 이 의미입니다"라고 말하세요.
3. **숫자는 적게, 비유는 많이.** 논문 숫자는 슬라이드에 있으니 읽지 말고 "무엇이 얼마나 좋아졌나"만 말하세요.
4. **자주 쓰는 비유 (노트에도 있음)**
   - VLA = "책으로 세상을 배운 사람(VLM)에게 운전 연수(로봇 데이터)를 시키는 것"
   - 행동 토큰화 = "연속적인 핸들 각도를 1~256단계 눈금으로 끊어 읽기"
   - 디퓨전/플로우 = "흐릿한 낙서에서 점점 선명한 동작을 그려내기"
   - 액션 청킹 = "한 걸음씩 생각하지 않고 '다음 1초 동작'을 한 번에 계획하기"
   - 이중 시스템 = "천천히 생각하는 뇌(System 2) + 반사적으로 움직이는 척수(System 1)"
   - FAST = "동작을 JPEG처럼 압축"
5. **모르는 질문이 나오면**: "좋은 질문입니다. 논문 원문을 확인해서 강의 자료 공유할 때 같이 답변드리겠습니다." — 절대 지어내지 않기.
