## A. 예상 질문 Top 10

**Q1. VLA랑 그냥 "로봇 + LLM"(예: LLM이 코드로 로봇 API를 호출)은 뭐가 다른가요?**
> LLM이 계획하고 미리 만들어진 기술(pick, place 함수)을 호출하는 방식(SayCan, Code-as-Policies 등)은 **기술 자체는 사람이 만들어 둬야** 합니다. VLA는 **모터 명령 수준까지 모델이 직접 출력**해서, 기술 자체를 데이터로 배웁니다. 최근에는 둘을 합쳐 고수준 VLM(계획, 도구 사용) + 저수준 VLA(동작)로 쓰는 추세입니다 (Gemini Robotics 1.5, Hi Robot).

**Q2. 행동을 토큰으로 출력하는 것과 디퓨전/플로우로 출력하는 것 중 뭐가 더 좋나요?**
> 정답은 "상황에 따라"입니다. 토큰은 VLM 구조를 그대로 쓸 수 있어 학습이 간단하고 언어 능력과 잘 어울리지만, 느리고 해상도가 제한됩니다. 플로우/디퓨전은 정교하고 빠른 연속 제어에 강합니다. 그래서 π0.5처럼 **학습은 토큰(FAST)으로, 실행은 플로우로** 하는 하이브리드가 나왔고, OFT처럼 단순 회귀가 벤치마크에서 가장 좋은 경우도 있습니다.

**Q3. 로봇 데이터는 얼마나 필요한가요? 우리 연구실에서도 할 수 있나요?**
> 사전학습된 VLA(π0, OpenVLA, SmolVLA, GR00T)를 가져와 **파인튜닝만 한다면 작업당 수십~수백 개 시연(수 시간)** 이면 됩니다. OpenVLA는 LoRA로 GPU 1장, SmolVLA는 일반 GPU에서 학습 가능합니다. 하드웨어는 LeRobot의 SO-101 같은 저가 팔로 시작할 수 있습니다. 대규모 사전학습 자체는 수천 시간 데이터와 수십~수백 GPU가 필요해 기업 규모입니다.

**Q4. 왜 로봇은 LLM처럼 빨리 발전하지 못하나요?**
> ① **데이터**: 인터넷 텍스트는 공짜로 수조 토큰, 로봇 데이터는 사람이 한 시간씩 조종해야 함. ② **실세계 평가**: LLM은 벤치마크를 자동으로 돌리지만, 로봇은 실제로 한 번씩 해봐야 함. ③ **안전·비용**: 실수하면 물건이 깨짐. ④ **몸이 다양함**: 로봇마다 행동 공간이 달라 데이터 공유가 어려움.

**Q5. VLA는 시뮬레이션에서 학습하면 안 되나요?**
> 쓰긴 씁니다 (GR00T의 합성 데이터, 벤치마크 LIBERO 등). 하지만 **sim-to-real gap**(천, 액체, 접촉 같은 물리를 정확히 시뮬레이션하기 어려움, 시각적 차이) 때문에 현재 최고 성능 모델들은 여전히 **실제 로봇 데이터 중심**입니다. 영상 생성 모델(월드 모델)로 합성 데이터를 만드는 방향이 빠르게 성장 중입니다.

**Q6. 파국적 망각(catastrophic forgetting)이 왜 문제고 어떻게 막나요?**
> 로봇 데이터로만 학습하면 VLM이 원래 알던 언어·상식을 잊어서, "멸종된 동물" 같은 지시를 이해하지 못하게 됩니다. 해결책은 ① 웹 데이터와 섞어 학습(co-training, RT-2·π0.5), ② VLM 일부를 얼리기(GR00T N1.5), ③ 행동 헤드의 그래디언트를 차단하기(Knowledge Insulation) 등입니다.

**Q7. 액션 청킹을 하면 반응이 느려지지 않나요? (예: 물건이 갑자기 움직이면?)**
> 맞습니다. 청크 전체를 실행하는 동안은 새 관측을 반영하지 못하는 트레이드오프가 있습니다. 그래서 청크의 **일부만 실행하고 다시 예측**하거나(receding horizon), 다음 청크를 **실행 중에 미리 계산**하는 Real-Time Chunking / 비동기 추론, 또는 **이중 시스템**(빠른 System 1이 고주파로 반응)을 씁니다.

**Q8. π0의 "Action Expert"는 왜 따로 두나요? 그냥 VLM이 다 하면 안 되나요?**
> VLM(3B)은 크고 느린데, 플로우 매칭은 **10번 반복 계산**이 필요합니다. 행동 부분만 작은 가중치(300M)로 처리하고, 이미지·언어 부분은 한 번만 계산해서 캐시하면 **빠르게 반복**할 수 있습니다. 또 이미지·언어 토큰과 행동 토큰은 성격이 매우 달라서 별도 가중치를 두는 게 학습에도 유리합니다.

**Q9. VLA가 틀린 행동을 할 때 안전은 어떻게 보장하나요?**
> 현재 VLA 자체에는 안전 보장이 없습니다. 실제 시스템에서는 ① 저수준 제어기의 힘/속도 제한, ② 작업 공간 제한, ③ 충돌 감지·비상 정지, ④ 사람 감독(teleop 개입) 등 **고전적 안전 장치를 바깥에 둡니다**. Gemini Robotics는 안전 관련 추론 벤치마크(ASIMOV)도 제안했습니다. VLA 안전성은 중요한 열린 연구 주제입니다.

**Q10. 앞으로 1~2년 VLA 연구의 핵심 주제는 뭘까요?**
> ① **RL / 경험으로부터 학습** (π*0.6), ② **추론하는 VLA** (생각 후 행동, ECoT, Gemini Robotics 1.5), ③ **사람 영상·월드 모델로 데이터 확장**, ④ **효율화**(작은 모델, 빠른 추론, 엣지 배포), ⑤ **평가 방법**(실세계 대규모 평가, RoboArena 같은 분산 평가), ⑥ 촉각 등 **새로운 감각** 추가.

## B. 추가 예상 질문 (짧게)

| 질문 | 짧은 답 |
|---|---|
| VLA는 몇 Hz로 돌아야 하나? | 작업마다 다름. 단순 집기는 3~10Hz도 가능, 정교한 양손 작업은 50Hz 이상. 청크로 보완. |
| 로봇 상태(proprioception)는 꼭 필요한가? | OpenVLA는 안 씀. π0 등은 사용. 상태를 쓰면 정밀해지지만 "상태만 보고 따라하는" 지름길 학습 위험도 있음. |
| 3D 정보(깊이, 포인트 클라우드)는 안 쓰나? | 대부분의 대형 VLA는 RGB만. 3D를 쓰는 연구(3D-VLA, SpatialVLA 등)도 활발. |
| 촉각은? | 아직 소수. 접촉이 많은 작업(조립, 삽입)에서 중요해 연구 증가 중. |
| 왜 PaliGemma를 백본으로? | 3B로 작아서 빠르고, 물체 위치·분할 등 공간 과제에 사전학습되어 로봇에 유리. |
| 플로우 매칭과 디퓨전의 차이? | 둘 다 노이즈→데이터 생성. 플로우는 직선 경로(속도장)를 학습해 더 적은 스텝으로 생성 가능, 수식이 단순. |
| OXE 데이터로 학습하면 내 로봇에서 바로 되나? | 보통 안 됨. 카메라 위치·로봇 형태가 다르면 파인튜닝 필요. 같은 로봇(WidowX, Franka)이면 어느 정도 zero-shot 가능. |
| LIBERO 97%면 다 풀린 것 아닌가? | LIBERO는 시뮬레이션이고 포화 상태. 실세계 일반화와는 거리가 있어 LIBERO-Plus, RoboArena 같은 더 어려운 평가가 등장. |
| VLA를 자율주행에도 쓰나? | 네, 같은 개념이 자율주행에도 적용됨 (예: 비전-언어-행동 주행 모델). 오늘은 조작(manipulation) 중심. |
| 오픈소스로 시작하려면? | LeRobot(Hugging Face) + SmolVLA 또는 π0/π0.5(openpi), OpenVLA. `05_참고자료.md` 참고. |

## C. 청중 참여 퀴즈 (강의 중 사용)

### 퀴즈 1 (Part 1 끝) — 다봉성
> 로봇 앞에 장애물이 있고, 시연 데이터 절반은 왼쪽으로, 절반은 오른쪽으로 피했습니다. MSE 회귀로 학습한 로봇은 어떻게 행동할까요?
- 정답: **정면으로 돌진** (두 답의 평균). → 그래서 분포를 표현할 수 있는 토큰(분류)이나 디퓨전/플로우가 필요.

### 퀴즈 2 (Part 2) — 토큰화 계산
> Δx 범위가 [-0.05m, +0.05m]이고 256개 bin으로 나눌 때, 한 bin의 크기는?
- 정답: 0.1m / 256 ≈ **0.39mm**. (생각보다 세밀! 하지만 범위가 넓어지면 거칠어짐 → 백분위수로 범위 정하는 이유)

### 퀴즈 3 (휴식 시간 슬라이드) — 생각해보기
> 로봇이 초당 50번 행동해야 하는데, 7B 모델 한 번 추론에 150ms가 걸린다면 어떻게 해야 할까요?
- 정답 예시: **액션 청킹**(한 번에 여러 스텝), **이중 시스템**(빠른 작은 모델), **작은 모델/양자화**, **비동기 추론**.

### 퀴즈 4 (RT-2 슬라이드) — Emergent capability
> RT-2에게 "멸종된 동물을 집어"라고 하면 테이블 위 (사과, 공룡 장난감, 컵) 중 무엇을 집을까요? 로봇 데이터에 "멸종"이라는 단어는 한 번도 없었습니다.
- 정답: **공룡 장난감**. VLM이 인터넷에서 배운 지식이 행동으로 전이됨.

### 퀴즈 5 (π0.5 슬라이드) — 데이터
> π0.5에서 웹 데이터(캡션, VQA)를 빼면 어떤 능력이 가장 떨어질까요?
- 정답: **처음 보는 물체**를 이해하고 다루는 능력 (언어 지시에서 처음 보는 물체 이름 이해).

### 마무리 퀴즈 (O/X)
1. VLA는 이미지와 언어를 입력받아 텍스트만 출력한다. (**X** — 로봇 행동을 출력)
2. OpenVLA는 행동을 256개 구간의 토큰으로 출력한다. (**O**)
3. π0는 디퓨전 대신 플로우 매칭으로 행동 청크를 생성한다. (**O**)
4. 로봇 데이터로만 파인튜닝하면 VLM의 상식이 더 좋아진다. (**X** — 파국적 망각)
5. 이중 시스템에서 System 1은 느리게 생각하는 부분이다. (**X** — System 1이 빠른 반사, System 2가 느린 사고)
