# 03. 논문 해설 — Part 3 "논문으로 보는 VLA의 진화"

> 각 논문을 **"왜 나왔나 → 핵심 아이디어(쉽게) → 구조 → 데이터 → 결과 → 한계 → 강의 포인트"** 순서로 정리했습니다.
> ★ 표시는 강의에서 시간을 가장 많이 쓸 논문입니다 (RT-2, OpenVLA, π0, π0.5).
> 숫자는 논문/공식 블로그 기준이며, 강의에서는 **"무엇이 얼마나 좋아졌나"** 만 말하면 충분합니다.

## 0. 배경: VLA 이전의 두 가지 핵심 기법

### 0-1. ACT / ALOHA (Zhao et al., RSS 2023) — "Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware"
- **ALOHA**: 약 2만 달러짜리 저가 양팔 원격조종 시스템 (리더 팔을 사람이 움직이면 팔로워 팔이 따라함).
- **ACT (Action Chunking with Transformers)**: 한 번에 **k=100 스텝**의 행동을 예측. CVAE(조건부 VAE)로 다봉성 처리, 겹치는 예측을 가중평균(temporal ensembling).
- 결과: 10분 분량(약 50개) 시연만으로 배터리 끼우기, 컵 뚜껑 열기 같은 정밀 작업 80~90% 성공.
- **의의**: "액션 청킹"이라는 개념을 대중화 → π0, GR00T 등 거의 모든 최신 VLA가 채택.

### 0-2. Diffusion Policy (Chi et al., RSS 2023)
- 이미지 생성에 쓰이던 **디퓨전 모델로 행동 시퀀스를 생성**.
- 여러 정답(다봉성)을 자연스럽게 표현, 여러 벤치마크에서 기존 방법 대비 평균 약 **46.9%** 향상.
- **의의**: "행동 출력 = 생성 모델 문제"라는 관점 → Octo, π0(플로우 매칭), GR00T(DiT)로 이어짐.
- 한계: 작업별로 처음부터 학습하는 "전문가(specialist)" 정책, 언어 이해 없음.

🎤 "VLA 이전에도 로봇 모방학습은 잘 되고 있었습니다. 다만 **작업마다 모델을 따로** 만들어야 했죠. VLA는 이걸 **하나의 범용 모델**로 만들려는 시도입니다."

## 1. RT-1 (Google, 2022.12) — "Robotics Transformer for Real-World Control at Scale"

**한 줄 요약**: 로봇 13대로 17개월간 모은 13만 개 시연으로 Transformer 정책을 학습해, 700개 이상의 지시를 수행한 "로봇계의 대규모 학습" 첫 사례.

### 왜 나왔나
- 그동안의 로봇 학습은 작업 하나, 데이터 조금. "데이터를 엄청 모으고 큰 모델을 쓰면 NLP/CV처럼 일반화가 될까?"

### 핵심 아이디어 & 구조 (쉽게)
```
이미지 6장(최근 기록) ─▶ EfficientNet-B3 (언어로 FiLM 조건화) ─▶ 이미지당 81토큰
                                                          ─▶ TokenLearner로 8토큰으로 압축
언어 지시 ─▶ Universal Sentence Encoder ─(FiLM)─┘
  → 총 48토큰 ─▶ Transformer (8층) ─▶ 행동 11차원 × 256 bin (분류)
```
- **FiLM**: 언어 임베딩으로 이미지 특징을 곱하고 더해서 "무엇을 봐야 할지" 조절.
- **TokenLearner**: 토큰 수를 줄여 **3Hz** 실시간 제어 가능하게.
- **행동 11차원**: 팔 7(위치3+회전3+그리퍼1) + 모바일 베이스 3 + 모드 1. 각 차원을 **256개 구간으로 이산화** → 분류 문제. (→ RT-2, OpenVLA의 행동 토큰화의 원조)
- 모델 크기: 약 **35M** 파라미터 (VLM 아님!)

### 데이터
- Everyday Robots 모바일 매니퓰레이터 **13대**, **17개월**, **약 13만 에피소드**, **700개 이상 지시** (집기, 놓기, 서랍 열기 등).

### 결과
- 학습에 본 작업 **97%** 성공, 처음 보는 지시 **76%**, 방해물 있을 때 83%, 배경 바뀔 때 59%.
- 시뮬레이션 데이터, 다른 로봇(Kuka) 데이터를 섞어도 원래 성능이 떨어지지 않음 → **데이터 흡수력(absorbency)**.

### 한계
- 인터넷 지식 없음 → 로봇 데이터에 없는 개념은 전혀 모름.
- 처음 보는 물체·환경 일반화 제한.

### 강의 포인트
- "VLA의 할아버지". **행동을 256개 bin으로 나눈 분류**라는 아이디어가 여기서 나왔다는 것만 기억시키면 됨.

## 2. ★ RT-2 (Google DeepMind, 2023.07) — "Vision-Language-Action Models Transfer Web Knowledge to Robotic Control"

**한 줄 요약**: 거대 VLM에게 **로봇 행동을 "숫자 문자열"로 말하게** 가르쳐서, 인터넷에서 배운 상식을 로봇 제어에 그대로 활용한 최초의 **VLA**.

### 왜 나왔나
- RT-1은 로봇 데이터에 있는 것만 할 수 있음. 반면 VLM(PaLI-X, PaLM-E)은 인터넷에서 엄청난 지식을 배웠음.
- 질문: "VLM의 지식을 로봇이 쓸 수 있게 하려면? → **VLM 자체가 행동을 출력하게 하면 되지 않을까?**"

### 핵심 아이디어 (쉽게)
**"행동도 그냥 언어다."**
- 로봇 행동 (종료여부, Δx, Δy, Δz, Δroll, Δpitch, Δyaw, 그리퍼) 8개 값을 각각 256 bin 정수로 바꿔서 **텍스트 문자열**로 표현:

```
질문: "What action should the robot take to pick up the apple?"
정답: "1 128 91 241 5 101 127 217"
```
- VLM은 이걸 **그냥 또 하나의 "언어"로** 학습 (이미지 캡셔닝, VQA와 같은 방식).
- 토큰 처리:
  - PaLI-X: 1000 이하 정수는 이미 고유 토큰이 있으므로 그대로 사용
  - PaLM-E: 가장 적게 쓰이는 256개 토큰을 행동 토큰으로 **덮어씀** (OpenVLA도 이 방법 사용)
- 추론 시 로봇 작업이면 **행동 토큰만 샘플링하도록 제한**(유효한 행동만 나오게).

### Co-fine-tuning (핵심 학습 비법)
- 로봇 데이터**만**으로 파인튜닝하지 않고, **원래의 인터넷 VQA/캡션 데이터와 섞어서** 함께 학습.
- 이유: 로봇 데이터만 보면 VLM이 원래 상식을 잊어버림(파국적 망각). 섞으면 **상식 유지 + 행동 학습**.
- 실험: co-fine-tuning > 로봇 데이터만 파인튜닝 > 처음부터 학습 (규모 클수록 차이 큼).

### 모델
- **RT-2-PaLI-X**: 5B / **55B**, **RT-2-PaLM-E**: 12B
- 55B 모델은 로봇에 못 올려서 **클라우드 TPU**에서 실행, **1~3Hz**.

### 결과 (약 6,000회 실제 로봇 평가)
- 본 적 있는 작업: RT-1과 비슷 (둘 다 잘함)
- **처음 보는 물체/배경/환경(일반화)**: RT-2 약 **62%** vs RT-1 약 **32%** → **약 2배**
- **Emergent capabilities (가르치지 않은 능력)** — 강의 하이라이트!
  - "**멸종된 동물**을 집어" → 공룡 장난감을 집음 (공룡=멸종 동물은 인터넷 지식)
  - "**즉석 망치로 쓸 수 있는 물건**을 집어" → 돌을 집음
  - "콜라 캔을 **테일러 스위프트** 사진으로 옮겨" → 사진 인식
  - "바나나를 **2+1의 합**으로 옮겨" → 숫자 3이 쓰인 곳으로 이동
  - "**피곤한 사람**에게 줄 음료" → 에너지 드링크
- **Chain-of-thought 변형**: 행동 전에 "Plan: pick rxbar chocolate"처럼 계획을 텍스트로 먼저 생성 → 더 복잡한 추론 가능.

### 한계
- **새로운 동작(skill)** 은 못 배움. 인터넷 지식은 "무엇을/어디로"를 도와줄 뿐, "어떻게 움직이는지"는 로봇 데이터에 있던 동작 범위 안에서만.
- 너무 큼 (55B), 느림 (1~3Hz), 비공개.

### 강의 포인트
- "**VLA라는 이름을 만든 논문**". 행동 = 텍스트 토큰이라는 단순하지만 강력한 아이디어.
- emergent 예시를 청중에게 퀴즈로 던지면 반응 좋음: "'멸종된 동물을 집어'라고 하면 로봇이 뭘 집었을까요?"
- 한계 ("새로운 동작은 못 배운다")를 꼭 짚기 → 이후 논문들의 동기.

## 3. Open X-Embodiment / RT-X (2023.10) — "Robotic Learning Datasets and RT-X Models"

**한 줄 요약**: 전 세계 21개 기관이 모은 **22종 로봇, 100만+ 궤적**을 하나의 포맷으로 통합한 "로봇계의 ImageNet"과, 이를 학습한 RT-1-X / RT-2-X.

### 왜 나왔나
- 연구실마다 로봇이 달라 데이터가 작고 파편화됨. "다른 로봇의 데이터도 내 로봇에 도움이 될까?" (**cross-embodiment transfer**)

### 핵심 내용
- **데이터**: 60개 데이터셋, 34개 연구실, **22종 로봇 형태**, **100만+ 궤적**, 527개 기술(skill). RLDS라는 공통 포맷으로 통일.
- 행동 공간을 **7차원 엔드이펙터 델타로 대략 통일** (좌표계 차이는 무시하고 그냥 학습).
- **RT-1-X**: 데이터가 적은 연구실에서, 각자의 원래 방법 대비 평균 **50% 향상**.
- **RT-2-X (55B)**: 다른 로봇 데이터 덕분에 emergent skill 평가에서 RT-2 대비 **약 3배**.

### 강의 포인트
- "로봇 데이터 부족" 문제에 대한 **커뮤니티 차원의 해법**. 이후 Octo, OpenVLA, π0 모두 OXE를 사전학습에 사용.
- 로봇이 다르더라도 **데이터를 합치면 서로 도움이 된다**는 것을 처음 대규모로 증명.

## 4. Octo (UC Berkeley 외, 2024.05) — "An Open-Source Generalist Robot Policy"

**한 줄 요약**: OXE 80만 궤적으로 학습한 **오픈소스** 범용 정책. 디퓨전 헤드 + 유연한 입출력 구조로 **새 로봇에 쉽게 파인튜닝**.

### 핵심 아이디어
```
[언어(T5) 토큰] [목표 이미지 토큰] [관측 이미지 토큰...] [readout 토큰]
        └──────────────── Transformer ────────────────┘
                                         readout 토큰 ─▶ 디퓨전 헤드 ─▶ 행동 청크(4스텝)
```
- **Readout 토큰**: BERT의 [CLS]처럼 정보를 모으는 특수 토큰. 이 토큰만 행동 헤드로 감.
- **블록 단위 어텐션**: 새 카메라나 새 행동 공간이 생기면 토큰/헤드만 추가하면 됨 → **파인튜닝 친화적**.
- 언어 지시 또는 **목표 이미지**로 작업 지정 가능.
- 크기: Octo-Small **27M**, Octo-Base **93M** (VLM 아님, 작음).

### 결과
- 약 100개 시연으로 새 로봇/새 관측·행동 공간에 몇 시간 내 파인튜닝 → 처음부터 학습 대비 크게 우수.

### 한계 & 의의
- VLM 기반이 아니라 언어 이해·상식이 약함. 그러나 **완전 오픈소스 범용 정책**의 시작 → OpenVLA로 이어짐.

## 5. ★ OpenVLA (Stanford·UC Berkeley·TRI·Google DeepMind 외, 2024.06) — "An Open-Source Vision-Language-Action Model"

**한 줄 요약**: RT-2 레시피를 **오픈소스 7B 모델**로 재현·개선. 55B RT-2-X보다 **7배 작은데 더 잘함**, 가정용 GPU에서 파인튜닝 가능.

### 왜 나왔나
- RT-2는 비공개 + 너무 큼. 연구자들이 **직접 쓰고, 고치고, 파인튜닝할 수 있는 VLA** 가 필요.

### 구조 (쉽게)
```
이미지(224×224) ─┬─▶ SigLIP  (무엇인지: 의미) ─┐
                 └─▶ DINOv2  (어디에: 공간)   ─┴─ concat ─▶ MLP projector ─┐
언어 지시 ──────────────────────────────────────────────────────▶ Llama 2 (7B) ─▶ 행동 토큰 7개
```
- 기반 VLM: **Prismatic-7B** (SigLIP + DINOv2 + Llama 2 7B)
- 행동: 7차원 × **256 bin** (RT-2 방식)
  - bin 범위를 min~max가 아닌 **1~99 백분위수**로 → 이상치 하나 때문에 해상도가 낭비되는 것 방지
  - Llama 토크나이저의 **가장 안 쓰이는 256개 토큰**을 행동 토큰으로 덮어씀
- 입력: 이미지 1장 + 언어. (로봇 상태, 과거 이미지 없음 → 단순)

### 데이터 & 학습
- OXE에서 선별한 **97만 궤적**. 64× A100 GPU로 **14일**, 27 에폭.
- 흥미로운 발견들:
  - VLM에서는 보통 비전 인코더를 얼리지만(freeze), **VLA에서는 비전 인코더도 같이 학습해야** 성능이 좋음 → 로봇에는 세밀한 공간 정보가 중요.
  - LLM 학습과 달리 **에폭을 여러 번(27회)** 돌려야 행동 토큰 정확도가 충분히 올라감.

### 결과
- 29개 작업, 2종 로봇(WidowX, Google Robot)에서 **RT-2-X(55B) 대비 절대 성공률 +16.5%p**, 파라미터는 7배 적음.
- 새 로봇(Franka) 파인튜닝: 처음부터 학습한 Diffusion Policy 대비 **+20.4%p** (특히 여러 물체·언어 지시가 섞인 작업에서 강함).
- **실용성**:
  - **LoRA**(파라미터의 1.4%만 학습)로 전체 파인튜닝과 동등 성능 → GPU 1장으로 파인튜닝
  - **4-bit 양자화**로 추론 메모리 절감, 성능 유지
  - 추론 약 **6Hz** (RTX 4090)

### 한계
- 느림 (토큰 7개 순차 생성, 액션 청킹 없음) → 고주파·정밀 작업 불리
- 이미지 1장, 상태 입력 없음 → 양팔·손목 카메라 활용 어려움
- 256 bin 해상도 한계

### 후속: OpenVLA-OFT (Kim, Finn, Liang, 2025.02) — "Fine-Tuning VLAs: Optimizing Speed and Success"
- OpenVLA를 파인튜닝할 때 **3가지를 바꿨더니** 극적으로 좋아짐:
  1. **병렬 디코딩**: 토큰을 하나씩이 아니라 한 번에 (빈 토큰 자리를 한 번의 forward로 채움)
  2. **액션 청킹**: 여러 스텝을 한 번에
  3. **연속 행동 + L1 회귀**: 256 bin 대신 MLP로 실수값 직접 출력
- 결과: LIBERO 평균 **76.5% → 97.1%**, 행동 생성 처리량 **약 26배**.
- 교훈: "행동을 **토큰으로 출력하는 게 꼭 최선은 아니다**" — 강의에서 Part 2의 비교표와 연결하기 좋음.

### 강의 포인트
- **"VLA 연구의 민주화"**: 코드·가중치·데이터 파이프라인 모두 공개 → 이후 수많은 연구의 베이스라인.
- 구조가 LLaVA와 거의 같다는 점 강조 → "VLM을 아는 사람은 VLA를 이미 절반 안다".
- OFT와 비교해 "행동 표현 방식이 성능과 속도를 얼마나 바꾸는지" 보여주기.

## 6. ★ π0 (Physical Intelligence, 2024.10) — "A Vision-Language-Action Flow Model for General Robot Control"

**한 줄 요약**: VLM(PaliGemma 3B)에 **플로우 매칭 기반 "행동 전문가"(300M)** 를 붙여 **50Hz 연속 행동**을 생성. 빨래 개기·테이블 치우기·상자 조립 같은 **정교하고 긴 작업**을 처음으로 범용 모델로 해낸 논문.

### 왜 나왔나
- RT-2/OpenVLA의 이산 토큰 방식은 **느리고 거칠어서** 빨래 개기 같은 정교한 고주파 작업이 어려움.
- 목표: **VLM의 일반화 능력 + 디퓨전 정책의 정교함**을 한 모델에.

### 구조 (쉽게)
```
 [이미지 2~3장] [언어] ─▶  PaliGemma VLM (3B)  ─────────┐   (어텐션으로 연결)
                             "큰 두뇌"                   ▼
 [로봇 상태 q] [노이즈 섞인 행동 청크] ─▶ Action Expert (300M) ─▶ 속도 벡터 v
                                         "행동 전문가"          (10번 반복 → 행동 청크 50스텝)
```
- **두 개의 전문가(Mixture of experts 비슷)**: 이미지·언어 토큰은 VLM 가중치로, 상태·행동 토큰은 별도의 작은 가중치(action expert)로 처리. 하지만 **같은 어텐션 안에서 서로를 봄**.
- **블록 단위 인과 어텐션**: [이미지+언어] → [상태] → [행동] 순으로, 앞 블록은 뒤 블록을 못 봄 → 이미지·언어 부분은 캐시해두고 행동 부분만 10번 반복 계산 → 빠름.
- **플로우 매칭**:
  - 학습: 정답 행동 청크에 노이즈를 섞고 "노이즈를 걷어낼 방향(속도)"을 맞추게 함
  - 추론: 노이즈에서 시작해 **10스텝** 적분 → 50스텝 행동 청크
  - 노이즈가 많은 구간(어려운 구간)을 더 자주 샘플링하도록 시간 분포 조정 (Beta 분포)
- **액션 청크 H=50**, 최대 **50Hz** 제어. 추론 약 **73ms** (RTX 4090, 카메라 3대).
- **여러 로봇 지원**: 행동/상태 벡터를 가장 큰 로봇(18차원) 기준으로 **zero-padding**.

### 데이터 & 학습 레시피 (LLM과 같은 2단계)
- **사전학습(pre-training)**: 자체 수집 약 **1만 시간**, **7종 로봇 구성**, **68개 작업** + OXE. "다양하지만 품질은 섞인" 데이터 → **넓은 기초 능력 + 실수 복구 능력**
- **사후학습(post-training)**: 목표 작업의 **고품질** 데이터 5~100시간 → **유창하고 능숙한 동작**
- 비유: "사전학습 = 다양한 경험(실수 포함), 사후학습 = 모범 사례 훈련". 사전학습만 하면 능숙하지 않고, 사후학습만 하면 실수에서 회복 못 함.
- 로봇 7종: UR5e(단일/양팔), Franka, 양팔 Trossen(ALOHA), 양팔 ARX, 모바일 Trossen, 모바일 Fibocom.

### 결과
- 사전학습 모델만으로(zero-shot) 셔츠 개기, 테이블 치우기, 식료품 담기 등에서 OpenVLA, Octo를 크게 앞섬.
- 사후학습 후: **빨래 건조기에서 꺼내 → 바구니에 담아 → 테이블로 옮겨 → 개기** (수십 분짜리 작업), 상자 조립, 계란 담기, 테이블 정리.
- 사전학습을 한 모델이 처음부터 학습한 모델보다 사후학습 효율이 훨씬 좋음 (최대 2배 이상).
- 2025.02 **openpi**로 코드·가중치 공개.

### 한계
- 사후학습 없이는 복잡한 작업 제한, 새로운 환경(처음 보는 집) 일반화는 아직 → π0.5의 동기.

### 강의 포인트
- **"VLM + 행동 전문가"** 구조가 이후 표준이 됨 (GR00T, SmolVLA 등도 비슷).
- **사전학습/사후학습 = LLM 레시피의 로봇 버전**을 명확히 보여준 논문.
- 빨래 개기 영상 필수!

## 7. FAST / π0-FAST (Physical Intelligence, 2025.01) — "Efficient Action Tokenization for VLA Models"

**한 줄 요약**: 행동 시퀀스를 **DCT + BPE로 압축**하는 토크나이저. 토큰 방식(자기회귀) VLA도 고주파 정교한 작업을 할 수 있게 함.

- 문제: 50Hz 단순 binning → 토큰 수 폭발 + 이웃 토큰이 거의 같아 "복사"만 학습.
- 해법: 정규화 → **DCT(주파수 변환)** → 양자화(대부분 0) → **BPE 압축** (자세한 설명은 `02_강의노트` 2.6절).
- 결과: π0-FAST가 π0(플로우)과 비슷한 성능, **학습 약 5배 빠름**. DROID 데이터로 학습한 모델이 새 환경에서 zero-shot으로 동작. **FAST+** 범용 토크나이저 공개.
- 단점: 자기회귀 디코딩이라 **추론이 느림** (플로우는 한 번에 청크 전체).
- 강의 포인트: "JPEG처럼 동작을 압축" 비유 한 줄이면 충분. π0.5 사전학습에 쓰였다는 연결고리.

## 8. ★ π0.5 (Physical Intelligence, 2025.04) — "A VLA with Open-World Generalization"

**한 줄 요약**: 여러 종류의 데이터(다른 로봇, 웹 데이터, 고수준 작업 설명, 사람의 말 코칭)를 **함께 학습(co-training)** 해서, **한 번도 가본 적 없는 집**에서 부엌·침실을 청소하는 VLA.

### 왜 나왔나
- π0은 "배운 환경에서 능숙"하지만 **새로운 집**(처음 보는 가구, 물건, 배치)에서는 약함.
- 질문: "로봇이 처음 보는 곳에서도 일하려면 어떤 데이터가 필요한가?"

### 핵심 아이디어 1: 이질적 데이터 Co-training
| 약어 | 데이터 | 역할 |
|---|---|---|
| MM | 모바일 매니퓰레이터 데이터 (약 **100개 집**, 약 **400시간**) | 목표 로봇·목표 작업 |
| ME | 다양한 환경의 고정형 팔 데이터 | 환경 다양성 |
| CE | 실험실 cross-embodiment 데이터 (OXE 포함) | 다양한 기술 |
| HL | 고수준 하위작업 라벨 ("베개를 집어라") | 작업 분해 능력 |
| WD | 웹 데이터 (캡션, VQA, 물체 위치 찾기) | 상식·물체 인식 |
| VI | 사람이 말로 한 단계씩 지시(verbal instruction) | 언어 지시 따르기 |

- 목표 로봇 데이터(MM)는 전체의 일부일 뿐, **나머지 데이터가 일반화를 만들어냄**.
- 실험: 웹 데이터를 빼면 **처음 보는 물체** 성능이 크게 떨어지고, 다른 로봇 데이터(ME/CE)를 빼면 전반적 성능 하락.
- **학습 환경 수 스케일링**: 학습에 쓴 집의 수를 늘릴수록 새 집 성능이 오르고, 약 100개 집 정도에서 **테스트 집에서 직접 학습한 모델에 근접**.

### 핵심 아이디어 2: 계층적 추론을 한 모델로 (Chain-of-thought for robots)
```
 "침실 정리해"  ─▶ π0.5 ─▶ (텍스트) "베개를 집어" ─▶ π0.5 ─▶ (행동 청크 50스텝, 플로우 매칭)
   고수준 명령          고수준 추론: 다음 하위작업               저수준 행동
```
- 같은 모델이 먼저 **"다음에 뭘 할지"를 텍스트로 예측**한 뒤, 그 텍스트를 조건으로 **행동을 생성**.
- 사람이 계획하고 → 몸을 움직이는 것과 비슷.

### 핵심 아이디어 3: 2단계 학습 (토큰 → 플로우)
- **사전학습 (280k 스텝)**: 모든 것을 **토큰**으로 — 행동은 **FAST 토큰**, 텍스트는 그대로. → 빠르고 효율적인 학습
- **사후학습 (80k 스텝)**: **Action Expert(플로우 매칭)** 를 추가해 연속 행동 생성 학습 → 추론 시 빠르고 정교
- 이 아이디어를 정리·일반화한 것이 **Knowledge Insulation** (2025.05):
  - VLM은 FAST 토큰으로 학습 (좋은 표현 학습)
  - Action Expert는 플로우로 학습하되 **그래디언트가 VLM으로 흘러가지 않게 차단(stop-gradient)**
  - → VLM의 지식이 "행동 전문가의 서툰 초기 학습"에 망가지지 않음, 학습 빠름, 언어 지시 따르기 향상

### 결과
- 학습에 없던 **3개의 실제 집**에서 부엌 정리, 침실 정리, 식기 넣기, 빨래 바구니 정리 등 수행 (수 분~10분 이상의 긴 작업).
- 언어로 "노란 컵을 싱크대에"처럼 세부 지시도 따름.
- 2025.09 openpi에 π0.5 가중치 공개.

### 한계
- 여전히 실수가 잦음 (물건을 못 찾거나, 서랍 여는 데 실패 등), 속도가 사람보다 느림.

### 강의 포인트
- **"데이터의 다양성 > 데이터의 양"** — 목표 로봇 데이터가 적어도 다른 데이터들이 일반화를 만든다.
- 모델이 **스스로 하위 작업을 말하고 행동**하는 구조 → 이후 "생각하는 VLA"(Gemini Robotics 1.5) 흐름과 연결.
- 처음 보는 집 청소 영상 필수!

## 9. Helix (Figure AI, 2025.02) — 이중 시스템 휴머노이드 VLA

**한 줄 요약**: 느리게 생각하는 **System 2 (7B VLM, 7~9Hz)** 와 빠르게 움직이는 **System 1 (80M, 200Hz)** 로 휴머노이드 상체 전체(35 자유도)를 제어.

- **S2**: 인터넷으로 사전학습된 오픈 7B VLM. 장면·언어 이해 → **잠재 벡터(latent)** 하나로 "무엇을 할지" 요약.
- **S1**: 80M Transformer. S2의 잠재 벡터 + 현재 이미지·상태 → **200Hz**로 손목, 손가락, 몸통, 머리까지 연속 제어.
- 데이터: 약 **500시간** 원격조종 데이터. 사람이 일일이 라벨링하지 않고, 영상을 보고 VLM이 "이 행동을 하려면 어떤 지시를 했을까?"를 **역으로 생성**해 언어 라벨로 사용.
- 시연: **두 로봇이 협업**해 처음 보는 식료품을 냉장고에 정리, 로봇에 탑재된 저전력 GPU에서 실행.
- 후속: Helix 02 (2026) — 전신 제어, 장시간 자율 작업.
- 강의 포인트: **이중 시스템 = "큰 모델의 지능"과 "빠른 제어"의 절충**. 카너먼 비유.

## 10. GR00T N1 (NVIDIA, 2025.03) — "An Open Foundation Model for Generalist Humanoid Robots"

**한 줄 요약**: 오픈 휴머노이드 VLA. **Eagle-2 VLM(System 2) + 플로우 매칭 DiT(System 1)**, 그리고 **데이터 피라미드**로 부족한 로봇 데이터를 보충.

### 구조
- 전체 **2.2B** (VLM 1.34B).
- **System 2**: NVIDIA **Eagle-2 VLM** (SigLIP-2 + SmolLM2), 약 10Hz. LLM의 **중간 층(12번째) 특징**을 사용 (마지막 층보다 행동 예측에 좋고 빠름).
- **System 1**: **DiT(Diffusion Transformer) + 플로우 매칭**, VLM 토큰에 cross-attention, **16스텝 액션 청크**, **120Hz**. 청크 생성 약 64ms (L40 GPU).
- **로봇별 인코더/디코더(MLP)**: 로봇 몸이 달라도 몸통은 공유.

### 데이터 피라미드
```
        ▲   실제 로봇 데이터 (적음, 비쌈, 정확)
       ▲▲▲  합성 데이터: 시뮬레이션(DexMimicGen), 영상 생성 모델로 만든 "신경망 궤적"
     ▲▲▲▲▲▲ 웹 데이터 + 사람 1인칭 영상 (많음, 공짜, 행동 라벨 없음)
```
- **행동 라벨이 없는 영상**은? → **잠재 행동(latent action, LAPA)**: 영상의 앞뒤 프레임 차이로부터 "가상의 행동"을 학습해 라벨로 사용.
- 영상 생성 모델로 로봇 영상을 대량 생성 → 역동역학 모델로 행동 라벨 부여.

### 후속
- **N1.5** (2025.06): VLM을 얼리고(freeze) 언어 지시 따르기 향상.
- **N1.6** (2025 말): Cosmos-Reason 기반 VLM, 2배 큰 32층 DiT.

### 강의 포인트
- "로봇 데이터가 부족하면 **시뮬레이션·생성 영상·사람 영상**으로 채운다" = NVIDIA다운 해법.
- 오픈 가중치 → 휴머노이드 연구의 베이스라인.

## 11. Gemini Robotics (Google DeepMind, 2025.03) & Gemini Robotics 1.5 (2025.09)

### Gemini Robotics (2025.03)
- **Gemini Robotics-ER (Embodied Reasoning)**: Gemini 2.0을 공간 이해에 특화 — 물체 가리키기(pointing), 3D 박스, 잡을 위치, 궤적 예측. 행동 출력은 안 함.
- **Gemini Robotics (VLA)**: 클라우드의 Gemini 기반 백본 + **로봇 내 로컬 액션 디코더** (이중 구조). 쿼리→응답 지연 수백 ms, 액션 청크로 **50Hz** 제어.
- 시연: ALOHA 2 양팔 로봇으로 **종이접기(여우)**, 도시락 싸기, 카드 게임 등 정교한 작업, 처음 보는 지시·물체에 강한 일반화.
- **Gemini Robotics On-Device** (2025.06): 로봇에서 직접 돌아가는 경량 버전.

### Gemini Robotics 1.5 (2025.09)
- **"Think before acting"**: 행동 전에 **자연어로 생각(추론)** 을 생성 → 다단계 작업 분해, 해석 가능성 향상.
- **Motion Transfer**: ALOHA, 양팔 Franka, 휴머노이드 Apptronik Apollo 등 **다른 몸의 데이터로 배운 동작을 서로 전이** → 한 모델로 여러 로봇.
- **Gemini Robotics-ER 1.5가 "지휘자(orchestrator)"**: 전체 계획, 웹 검색 같은 **도구 사용**(예: "지역 분리수거 규칙을 검색해서 쓰레기 분류"), VLA에게 단계별 지시.
- 2026.04 **ER 1.6** 공개 (계기판 읽기 등 공간·물리 추론 강화).

### 강의 포인트
- **에이전트(Agent) + VLA** 흐름: 고수준 "두뇌"(ER, 도구 사용) + 저수준 "손"(VLA).
- LLM에서 "reasoning 모델"이 뜬 것처럼, **VLA도 생각하고 행동하는 방향**으로.

## 12. π*0.6 & RECAP (Physical Intelligence, 2025.11) — "A VLA That Learns From Experience"

**한 줄 요약**: 시연 따라하기(모방학습)를 넘어, 로봇이 **직접 해본 경험과 사람의 교정**으로 스스로 실력을 올리는 **강화학습(RL) 레시피**.

### 왜 나왔나
- 모방학습은 **시연자 수준을 못 넘고**, 실수에서 배우지 못함 (1.8절 누적 오차).
- LLM도 사전학습 → 지도학습 → **RL(RLHF, reasoning RL)** 로 발전했듯, 로봇도 RL 단계가 필요.
- 그런데 VLA(수 B 파라미터, 플로우 매칭)에 PPO 같은 기존 RL을 그대로 적용하기 어려움.

### RECAP = RL with Experience & Corrections via Advantage-conditioned Policies (쉽게)
1. **데이터 수집**: 시연 + 로봇이 자율로 해본 시도(성공/실패) + 실패 직전에 사람이 개입해 교정한 데이터.
2. **가치 함수(value function) 학습**: "지금 상태에서 작업 완료까지 얼마나 남았나(얼마나 잘 되고 있나)"를 예측하는 모델.
3. **어드밴티지(advantage) 계산**: 각 행동이 **평균보다 나았나/못했나** (가치가 올라갔으면 좋은 행동).
4. **어드밴티지 조건부 정책**: 프롬프트에 "Advantage: positive / negative" 같은 표시를 붙여 **모든 데이터를 학습**(나쁜 행동도 "나쁜 예"로 학습).
5. **실행 시엔 항상 "positive"로 조건** → 좋은 행동 쪽 분포에서 샘플링.
6. 이 과정을 반복 (수집 → 학습 → 수집...).

🎤 비유: "운동 코치가 영상 보며 '이 동작은 좋았어, 이건 별로였어'라고 태그를 달아주고, 선수는 실전에서 '좋았던 동작'만 떠올리며 하는 것."

### 결과
- 가장 어려운 작업들에서 **처리량(시간당 성공 수) 2배 이상**, **실패율 약 절반**.
  - 다양한 옷 빨래 개기: 시간당 약 4개 → 8개 이상, 성공률 약 40% → 75% 이상
  - 상자 조립, **에스프레소 만들기**(하루 종일 연속 운영)
- 같은 데이터에서 AWR, PPO 같은 기존 RL 방법보다 우수.

### 강의 포인트
- **"모방 → 경험"**: VLA의 다음 단계는 RL. LLM 발전사와의 평행 구조를 다시 강조.

## 13. π0.7 (Physical Intelligence, 2026.04) — "A Steerable Generalist Robotic Foundation Model with Emergent Capabilities"

**한 줄 요약**: 언어 지시뿐 아니라 **하위작업 지시, 하위목표 이미지, 에피소드 메타데이터(품질·속도·전략)** 같은 다양한 컨텍스트로 조건화해 "조종 가능한(steerable)" 5B 범용 모델.

- 핵심: 품질이 섞인 데이터(서툰 시연, 실패, 이전 모델의 궤적)도 **"이건 어떤 품질/전략의 데이터"라는 메타데이터와 함께** 학습 → 추론 시 원하는 품질·전략을 지정.
- 결과: 전문가(specialist) 파인튜닝 모델 수준의 성능을 범용 모델로 달성, **조합적 일반화**(배운 기술을 재조합해 처음 보는 작업 수행 — 예: 말로 단계별 코칭받아 에어프라이어로 고구마 조리), 다른 로봇으로의 zero-shot 전이.
- 처음 보는 작업은 아직 60~80% 수준(학습 분포 내 작업 >90%).
- 강의 포인트: "로봇에게도 **프롬프트 엔지니어링/코칭**이 가능해지는 시대"로 마무리하기 좋음.
