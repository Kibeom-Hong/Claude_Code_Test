# 4주차 논문 해설 — BeT · Diffusion Policy · ACT

> 강의 중 질문에 답할 수 있도록 **논문 세부까지** 정리했습니다. 각 논문은
> **기본 정보 → 한 줄 요약 → 풀고 싶은 문제 → 방법(쉽게 → 정확하게) → 실험 → ablation → 한계·후속 → 강의에서 보여줄 것** 순서입니다.
> ⚠️ 수치는 논문 기준 기억/검색으로 정리한 것이며, 표시(※)한 값은 발표 전에 원문 표를 한 번 확인하세요.

## 공통 배경: 왜 이 세 편인가

2022~2023년에 "BC는 원래 안 된다"는 통념을 깨고 **소규모 시범만으로 실제 로봇의 정밀 조작**을 해낸 세 방법입니다. 셋의 공통 결론:

1. **출력 표현이 전부다** — 같은 데이터·같은 크기 모델이라도 행동을 어떻게 표현하느냐(분류/생성/잠재변수)가 성패를 가름
2. **여러 스텝을 한 번에 예측하라** — action chunking (BeT는 관측 히스토리 기반 시퀀스 모델링, DP·ACT는 명시적 chunk)

이 두 결론이 그대로 VLA 설계의 두 축(행동 표현, chunk 길이)이 됩니다.

## 1. BeT — Behavior Transformers: Cloning k modes with one stone

| 항목 | 내용 |
|---|---|
| 저자 | Nur Muhammad (Mahi) Shafiullah, Zichen Jeff Cui, Ariuntuya Altanzaya, Lerrel Pinto (NYU) |
| 학회 | NeurIPS 2022 · arXiv:2206.11251 |
| 코드 | github.com/notmahi/bet |

### 한 줄 요약
연속 행동을 **k-means로 k개 군집(=행동 어휘)** 으로 만들고, Transformer가 **어느 군집인지 분류 + 군집 중심에서의 오프셋 회귀**를 하게 해서, 여러 행동 모드를 한 모델로 재현.

### 풀고 싶은 문제
- 사람이 **목표 없이 자유롭게 놀면서 모은 데이터(play data)** 나 여러 사람의 시범에는 행동 모드가 많음
- 기존 방법들:
  - MLP + MSE: 모드 평균 → 실패
  - 가우시안 혼합(GMM), 정규화 흐름(flow), VAE: 모드 표현은 가능하지만 학습이 까다롭고 고차원에서 불안정
  - IBC(암묵적 정책, 에너지 모델): 표현력은 좋지만 학습·추론이 느리고 불안정
- 발상: **"언어 모델은 다봉성을 softmax로 쉽게 다룬다. 행동을 어휘로 만들면 되지 않나?"**

### 방법 (쉽게)
1. 시범 데이터의 모든 행동 벡터 {a}를 **k-means**로 k개 군집화 → 중심 {c_1,…,c_k}
2. 각 행동 a = c_j + r (j = 가장 가까운 중심, r = 잔차)
3. **minGPT**(작은 GPT)에 최근 h개 관측 (o_{t−h+1}, …, o_t)을 넣음
4. 각 시점마다 두 가지를 출력:
   - **군집 확률** p(j | 관측) — k개 로짓 → softmax
   - **모든 군집의 오프셋** r̂_1, …, r̂_k (각각 행동 차원 크기)
5. 실행 시: 군집 j를 확률대로 **샘플** → a = c_j + r̂_j

### 방법 (정확하게): 손실
```
L = Focal( p(·|o), j* )  +  λ · || r̂_{j*} − (a − c_{j*}) ||²
```
- **Focal loss**: 교차엔트로피에 (1−p)^γ 가중치를 곱해, 이미 잘 맞히는 쉬운 샘플의 비중을 줄임 → 드문 군집도 학습
- **Masked multi-task offset loss**: 정답 군집 j*의 오프셋만 학습 (다른 군집의 오프셋은 그 군집이 정답일 때만 학습됨)
- 관측 히스토리를 쓰는 이유: 현재 관측만으로는 "지금 어느 모드를 수행 중인지"가 모호할 수 있음 (예: 부엌 작업의 순서)

### 실험
| 환경 | 다봉성의 종류 |
|---|---|
| CARLA 자율주행 | 건물을 왼쪽/오른쪽으로 돌아가는 두 경로 |
| Multimodal Block Pushing | 두 블록 중 어느 것을 어느 목표 칸으로 먼저 밀지 |
| Franka Kitchen (Relay Kitchen) | 7개 하위작업(전자레인지, 주전자, 전등, 서랍 등) 중 **어떤 순서로** 수행할지 |

- 평가: (1) 과제 성공(완료한 하위작업 수 등), (2) **모드 포착** — 생성된 행동의 다양성(예: 수행한 작업 순서의 엔트로피)이 시범 데이터와 얼마나 비슷한가
- 결과 메시지: BeT는 성공률에서 기존 방법들보다 우수하면서, **시범에 있던 여러 모드(경로·순서)를 골고루 재현**. MLP BC는 모드가 섞여 실패
- 원 논문 실험은 시뮬레이션 중심 (실제 로봇은 후속 C-BeT에서)

### Ablation에서 기억할 것
- 군집 수 k: 너무 작으면 정밀도·모드 부족, 너무 크면 각 군집 데이터가 적어 분류가 어려움 → 과제별 튜닝 필요
- 오프셋 제거 시 성능 하락 → **이산 선택 + 연속 보정의 분업이 핵심**
- 히스토리 길이도 성능에 영향

### 한계
- k-means 군집 수에 민감, 군집이 행동 공간을 균일하게 덮지 못함
- 고정밀 조작에서는 이산화 흔적 (데모 그림 (2)의 계단 현상)
- 원 논문은 **목표·언어 조건이 없는** 정책 → "무엇을 할지" 지시 불가

### 후속
- **C-BeT** (Conditional BeT, "From Play to Policy", 2022): 목표 조건 추가, 실제 부엌 로봇
- **VQ-BeT** (2024): k-means 대신 **잔차 벡터 양자화(Residual VQ-VAE)** 로 행동 어휘를 학습, 행동 시퀀스(chunk) 단위 토큰화
- **계보**: RT-1/RT-2/OpenVLA의 "차원별 256 bin 균등 이산화", FAST(DCT+BPE) 모두 "행동을 어휘로" 라는 같은 정신

### 강의에서 보여줄 것
- 논문의 방법 그림(k-means → 분류 + 오프셋 구조)
- Franka Kitchen 결과: 여러 순서로 작업을 수행하는 장면

## 2. Diffusion Policy — Visuomotor Policy Learning via Action Diffusion

| 항목 | 내용 |
|---|---|
| 저자 | Cheng Chi, Zhenjia Xu, Siyuan Feng, Eric Cousineau, Yilun Du, Benjamin Burchfiel, Russ Tedrake, Shuran Song (Columbia, TRI, MIT) |
| 학회 | RSS 2023 · 확장판 IJRR 2024 · arXiv:2303.04137 |
| 코드/영상 | diffusion-policy.cs.columbia.edu |

### 한 줄 요약
로봇 정책을 **"관측을 조건으로 한 행동 시퀀스의 조건부 denoising diffusion"** 으로 표현. 4개 벤치마크 15개 과제에서 기존 최고 대비 **평균 46.9% 향상**.

### 풀고 싶은 문제
- 명시적 정책(MSE, GMM, 이산화)은 다봉성·고차원 행동 시퀀스 표현에 한계
- 암묵적 정책 **IBC**(Implicit BC, 에너지 기반 모델)는 표현력은 좋지만 **정규화 상수 Z** 추정을 위해 음성 샘플이 필요 → 학습 불안정
- 발상: 이미지 생성에서 검증된 diffusion을 행동에 쓰자

### 방법 (쉽게)
```
입력(조건): 최근 관측 T_o = 2 스텝 (이미지 + 로봇 상태)
출력(생성): 행동 시퀀스 T_p = 16 스텝
실행:       앞 T_a = 8 스텝만 실행 → 새 관측 → 다시 생성 (receding horizon)
```
- 학습: 2주차 DDPM 그대로. 정답 행동 시퀀스 A⁰에 k단계 노이즈를 섞어 A^k를 만들고
  ```
  L = || ε − ε_θ(O_t, A^k_t, k) ||²
  ```
- 추론: 노이즈 A^K에서 시작해 K번 denoising (학습 K=100, 실행은 DDIM으로 10스텝 → 약 0.1초, RTX 3080)

### 방법 (정확하게): 설계 선택들
**① 관측은 "조건"이지 생성 대상이 아니다**
- 관측과 행동의 결합분포 p(A, O)가 아니라 **조건부 p(A | O)** 만 모델링 → 관측 특징을 한 번만 계산하고 denoising 반복에서 재사용 → 빠름

**② 네트워크 두 가지**
| | CNN 기반 | Transformer 기반 (time-series diffusion transformer) |
|---|---|---|
| 구조 | 1D 시간축 합성곱 U-Net | minGPT 계열, 행동 토큰에 causal self-attention |
| 조건 주입 | **FiLM**: 관측 특징 + 스텝 k로 각 채널의 scale/bias 조절 | **cross-attention**: 행동 토큰이 관측 임베딩에 질의 |
| 권장 | 기본값. 하이퍼파라미터에 덜 민감 | 행동이 급변하는 과제(속도 제어 등)에서 유리, 튜닝 필요 |

**③ 비전 인코더**
- ResNet-18을 **사전학습 없이** 정책과 **end-to-end**로 학습 (카메라마다 별도)
- 전역 평균 풀링 → **spatial softmax**(특징맵에서 "어디"를 좌표로 뽑는 풀링, 공간 정보 보존)
- BatchNorm → **GroupNorm** (EMA 가중치와 함께 쓸 때 안정)

**④ 위치 제어 > 속도 제어**
- 대부분의 기존 BC는 속도(델타) 제어를 씀. DP는 **절대 위치 목표**가 더 잘 맞음
- 이유: 위치 제어는 다봉성이 더 뚜렷하지만(DP는 이걸 잘 다룸), **누적 오차에 덜 민감**하고 행동 시퀀스 예측과 궁합이 좋음

**⑤ IBC와의 관계 (3주차 연결)**
- 에너지 모델 p(a|o) ∝ exp(−E(a,o))는 Z(o) 계산이 어려움
- DP는 **∇_a log p(a|o) = −∇_a E** (score)를 학습 → Z가 미분에서 사라짐 → 음성 샘플 불필요, 안정적
- 즉 "3주차: diffusion 학습 = score 학습"의 실용적 이득

### 실험
**시뮬레이션 (4개 벤치마크, 15개 과제)**
- **Robomimic**: Lift, Can, Square, Transport, ToolHang (사람 숙련 시범 ph / 다수 시범자 mh)
- **Push-T**: T자 블록을 목표 위치·자세에 밀어 넣기 (접촉이 많고 다봉적)
- **Multimodal Block Pushing**, **Franka Kitchen** (BeT와 같은 과제)
- 비교: **LSTM-GMM**(BC-RNN), **IBC**, **BET**
- 결과: 거의 모든 과제에서 최고, 평균 46.9% 향상. 특히 다봉성이 큰 과제와 긴 과제에서 격차 큼

**실제 로봇 (UR5 등)**
- Real Push-T, **머그컵 뒤집기**(6자유도 회전), **소스 붓기·펴 바르기**(액체·유연한 동작)
- 방해(블록을 치우기, 손으로 가리기)에도 재계획으로 복구
- IJRR 확장판: 양팔 과제(에그비터, 매트 펼치기, 셔츠 접기 등) 추가

### Ablation에서 기억할 것
- **행동 시퀀스 길이(T_p)·실행 길이(T_a)**: 너무 짧으면 일관성 부족(모드 전환), 너무 길면 반응성 저하 → T_a=8 근처가 좋음
- **지연(latency) 강건성**: 행동 시퀀스를 미리 만들어 두므로 추론 지연이 있어도 성능 유지
- 위치 vs 속도 제어 비교

### 한계
- **느린 추론**: 반복 denoising (DDIM 10스텝으로 줄여도 수십~100ms)
- 여전히 **과제별(single-task)** 학습, 언어 조건 없음
- 데이터가 매우 적으면 여전히 어려움

### 후속과 유산
- **Octo**(2024): Transformer 백본 + diffusion head
- **π0**(2024): diffusion 대신 **flow matching** (적은 스텝) + VLM
- **GR00T N1**(2025): DiT(diffusion transformer) + flow matching head
- **UMI**(2024, 11주차): 손으로 드는 그리퍼로 데이터 수집 + Diffusion Policy
- **3D Diffusion Policy**, **Consistency Policy**(1~몇 스텝 증류) 등 파생 다수

### 강의에서 보여줄 것
- 프로젝트 페이지의 Push-T 영상 (방해에 대한 복구)
- 논문 그림: 명시적 정책 / 암묵적 정책 / Diffusion Policy 비교 그림, 그리고 T_o–T_p–T_a 타임라인 그림

## 3. ACT / ALOHA — Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware

| 항목 | 내용 |
|---|---|
| 저자 | Tony Z. Zhao, Vikash Kumar, Sergey Levine, Chelsea Finn (Stanford, Meta, UC Berkeley) |
| 학회 | RSS 2023 · arXiv:2304.13705 |
| 코드/영상 | tonyzhaozh.github.io/aloha |

### 한 줄 요약
2만 달러 이하 저가 양팔 원격조종 장비 **ALOHA**와, 미래 **100스텝 행동을 한 번에 회귀**하는 **ACT(Action Chunking with Transformers)** 로, 과제당 **10분(50개) 시범**만으로 정밀 양팔 조작 80~90% 성공.

### 풀고 싶은 문제
- 정밀 조작(건전지 끼우기, 얇은 뚜껑 열기)은 보통 고가 로봇 + 정밀 센서가 필요
- 저가 로봇은 부정확 → **학습으로 보상**할 수 없을까?
- 그런데 정밀 과제는 작은 오차가 치명적 → BC의 **누적 오차**가 특히 심각
- 사람 시범은 **들쭉날쭉**(같은 과제도 매번 다름)

### ALOHA 하드웨어
- 팔로워: **ViperX 6자유도 팔 × 2**, 리더: **WidowX 팔 × 2** (사람이 직접 잡고 움직임, 관절 공간 1:1 대응)
- 카메라 4대: 위(top), 앞(front), **양 손목(wrist) 각 1대**
- **50Hz** 제어, 총 비용 약 2만 달러 이하, 3D 프린팅 부품 + 기성품
- 사용자 연구: 조종 주파수를 50Hz → 5Hz로 낮추면 사람도 과제를 훨씬 느리고 어렵게 수행 → **고주파 제어가 정밀 조작에 중요**

### ACT 방법 (쉽게)
```
입력: 이미지 4장 + 관절 위치 14개
출력: 미래 k = 100 스텝의 목표 관절 위치 (14 × 100), 한 번의 forward
손실: L1 (L2보다 정밀 과제에서 잘 됨)
```

### ACT 방법 (정확하게)
**① CVAE 구조**
- **인코더** (훈련 때만 사용, BERT 비슷한 Transformer): 입력 = [CLS] 토큰 + 현재 관절 + **정답 행동 시퀀스(100개)** → [CLS] 출력으로 z의 평균·분산 (z는 32차원) — 속도를 위해 이미지는 넣지 않음
- **디코더** (= 실제 정책):
  - 카메라마다 **ResNet-18** → 특징맵을 펼쳐 토큰화 (카메라 4대 → 약 1,200개 토큰)
  - + 관절 토큰 + z 토큰 → **Transformer 인코더**
  - **Transformer 디코더**가 고정된 100개 query(DETR 방식)로 100개 행동을 **병렬 출력**
- 손실: `L = L1(복원) + β · KL(q(z|a,s) || N(0,I))`, β = 10
- 실행 시: 인코더 버리고 **z = 0** (사전분포의 평균) → 결정론적 정책
- 모델 약 80M 파라미터, 과제당 학습 약 5시간(단일 GPU), 추론 약 0.01초 (※ 수치는 원문 확인 권장)

**② Temporal Ensembling**
- 매 스텝(50Hz) 새로 chunk를 예측 → 현재 시점에 대한 예측이 최대 k개 겹침
- `a_t = Σ_i w_i · Â_t^{(i)} / Σ_i w_i,   w_i = exp(−m · i)` (i=0이 가장 오래된 예측)
- m이 작을수록 새 관측을 빠르게 반영. 추가 학습 비용 없음, 추론만 매 스텝

### 실험
**실제 과제 6개** (과제당 시범 50개, 벨크로 등 일부는 더 많음)
| 과제 | 어려운 점 |
|---|---|
| Slide Ziploc (지퍼백 열기) | 양손 협응, 얇은 지퍼 |
| Slot Battery (건전지 끼우기) | mm 단위 정밀 삽입 |
| Open Cup (투명 소스컵 뚜껑 열기) | 투명 물체 인식, 섬세한 힘 |
| Thread Velcro (케이블 타이 벨크로 끼우기) | 가장 어려움, 변형 물체 + 정밀 |
| Prep Tape (테이프 뜯어 붙이기) | 긴 작업 |
| Put On Shoe (신발 신기기) | 큰 변형 물체, 양손 |

**시뮬레이션 2개**: Cube Transfer, Bimanual Insertion (스크립트 시범 / 사람 시범 두 버전)

**결과**
- ACT: 대부분 과제에서 **80~90%대** (건전지·지퍼백·신발 등), 벨크로는 **20%대**로 가장 낮음 (※ 과제별 수치는 원문 Table 확인)
- 비교: BC-ConvMLP, **BeT**, **RT-1**, **VINN**(최근접 이웃) → 실제 정밀 과제에서 대부분 0%에 가까움

### Ablation에서 기억할 것
1. **Chunk 크기 k**: k=1(청킹 없음)에서 성능이 매우 낮고, k를 키울수록 크게 향상 → 청킹이 핵심. 게다가 **다른 방법(BC-ConvMLP, VINN)에도 청킹을 붙이면 좋아짐** → 청킹은 ACT만의 트릭이 아니라 일반 원리
2. **Temporal ensembling**: ACT에서 추가 향상, 동작이 부드러워짐
3. **CVAE**: 스크립트 데이터(일관됨)에서는 CVAE 유무 차이가 거의 없지만, **사람 데이터에서는 CVAE를 빼면 성능이 급락** → CVAE가 사람의 들쭉날쭉함을 흡수
4. **제어 주파수**: 50Hz 조종이 5Hz보다 사람에게도 훨씬 쉬움 → 고주파 데이터·제어의 중요성

### 한계
- 과제별 학습(single-task), 언어 조건 없음
- z=0 고정으로 실행 시에는 사실상 **한 가지 스타일만** 출력 (진짜 다봉 샘플링은 아님)
- 회귀 기반이라 모드가 완전히 다른 경우(좌/우)엔 여전히 위험 → 후속 연구 중 일부는 diffusion head로 교체(예: ALOHA Unleashed)

### 후속과 유산
- **Mobile ALOHA**(2024): 바퀴 달린 ALOHA, 요리·청소 등 전신 모바일 조작, co-training
- **ALOHA 2**(2024, Google DeepMind): 개선된 하드웨어 → Gemini Robotics의 주력 플랫폼
- **ALOHA Unleashed**(2024): 대규모 데이터 + diffusion 정책
- **LeRobot**의 기본 정책으로 ACT 제공 → 저가 SO-100/101 팔 입문 표준
- π0의 **chunk 50스텝 @ 50Hz**, 거의 모든 VLA의 action chunking이 ACT의 직계 유산

### 강의에서 보여줄 것
- 프로젝트 페이지 영상: 건전지 끼우기, 컵 뚜껑 열기, (보너스) 탁구공 저글링·케이블 타이 같은 원격조종 데모
- 논문 그림: ALOHA 장비 사진, ACT 구조 그림(CVAE 인코더 + 디코더), temporal ensembling 그림
