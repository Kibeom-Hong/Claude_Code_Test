> "지난 2주 동안 그림 그리는 기술, 생성모델을 배웠습니다. 오늘부터 드디어 로봇입니다. 오늘 수업은 사실상 **VLA 논문을 읽기 위한 문법 시간**입니다. 오늘 배우는 네 단어 — 모방학습, 누적 오차, 다봉성, action chunking — 가 앞으로 읽을 모든 VLA 논문의 서론과 방법에 나옵니다."

🎤 **3주 복습 (2분)** — 칠판 한쪽에 지난주 결론 한 줄을 다시 씁니다.
```
조건부 생성모델 = 로봇 정책     (c = 관측, x = 행동)
```
> "지난주에 이 등식을 써 두었죠. 오늘 세 번째 논문(Diffusion Policy)이 이 등식을 그대로 논문으로 만든 것입니다. 기억해 두세요."

🖊 **용어 정의 3줄 (5분)** — 원안 그대로 칠판에:
```
정책 π(a|s): 관측 s(카메라 이미지, 관절 각도)를 받아 행동 a를 내는 함수 = 로봇의 두뇌
시범(demonstration): 사람이 원격조종(teleoperation)으로 로봇을 움직이며 기록한 (s, a) 시퀀스
모방학습 / Behavior Cloning(BC): 시범으로 π를 지도학습 — "s를 보면 사람이 했던 a를 내라"
```
- 원격조종 방법을 짧게 보여주기(📽 4): **리더–팔로워 팔**(ALOHA: 사람이 작은 팔을 움직이면 큰 팔이 따라함), VR 컨트롤러, 스페이스마우스.
- 수식 한 줄 (📽 5):
```
min_θ  E_(s,a)~D [ −log π_θ(a | s) ]      (또는 || π_θ(s) − a ||²)
```
> "이미지 분류와 똑같습니다. 입력이 사진, 정답이 '고양이' 대신, 입력이 카메라 화면, 정답이 '사람이 그때 움직인 방향'일 뿐이죠. **그럼 끝난 것 아닌가요?**" (잠깐 멈춤)

✅ 체크: "BC가 지도학습이라는 것"에 모두 고개를 끄덕이면 넘어갑니다. 반박하는 학생이 있으면 "좋습니다, 그게 오늘 주제"라고 받습니다.

**B-3. 고전적 해법 DAgger (6분)** 📽 9
🖊
```
DAgger (Dataset Aggregation, Ross et al. 2011)

 ② π를 실제로 굴림 → 로봇이 이상한 상태들에 도달
 ③ 그 상태들을 전문가에게 보여주고 "여기선 뭘 해야 하나요?" 라벨 받기

```
> "원리적으로 옳습니다. 로봇이 실제로 가는 상태 분포에서 라벨을 받으니까요. 문제는 **전문가가 계속 옆에 대기**해야 한다는 것. 로봇 한 대에 사람 한 명이 붙어 있어야 합니다."
- 14주차 연결 한 줄: "이 '사람이 옆에서 교정' 정신은 14주차 HIL-SERL, π*0.6의 '교정 데이터'로 부활합니다."

**B-4. 현대적 처방 두 가지 (5분)** 📽 10

```
처방 1: 데이터를 다양하게 — 실수·복구 장면까지 포함해 많이  (→ 9~11주 데이터 스케일링)

```
✅ 체크 질문: "왜 사람 시범 데이터에는 복구 장면이 없나요?" → "사람은 잘하니까". 이 답이 나오면 통과.

**C-5. Action Chunking 정의 (5분)** 📽 15–16 — 🖊 칠판 **오른쪽 구역에 박스로, 수업 끝까지 유지**
```
┌─ Action Chunking ──────────────────────────────────────────┐
│ 현재 관측 s를 보고 행동 1개가 아니라 미래 행동 k개를 한 번에 예측  │
│  (예: k = 16 ~ 100)                                          │
│ 효과 1: 결정 횟수 1/k → 누적 오차 기회 감소        (적 1호 대응) │
│ 효과 2: 한 뭉치 = 하나의 계획 → 시간적 일관성      (적 2호 대응) │
│ 효과 3: 추론 1번으로 k스텝 → 무거운 모델도 실시간    (후반부 복선) │
└────────────────────────────────────────────────────────────┘
```
> "비유하면, 운전하면서 매 순간 핸들을 새로 결정하는 게 아니라 '앞으로 2초는 이렇게 돌리자'고 계획하는 것입니다. 오늘 볼 세 논문 모두 이걸 씁니다."

✅ 체크: "chunking이 두 적 모두에 도움이 되는 이유?" → 효과 1, 2를 말할 수 있으면 통과.

### D. 해법 1 — BeT (1:05–1:25) 📽 18–22

**D-1. 문제 인식 (4분)** 📽 18
> "BeT 저자들의 질문: Transformer로 행동을 예측하고 싶은데 행동은 연속값이고 봉우리가 여러 개다. 그런데 **언어 모델은 다봉성을 어떻게 다루죠?** '나는 오늘 ___'의 빈칸에 '밥을', '학교에', '잠을' 모두 가능하지만 GPT는 전혀 곤란해하지 않습니다. **어휘가 이산적이라서 softmax로 확률을 나눠주면 끝이니까요.** → 그럼 행동도 이산화하자!"

**D-2. 방법 2단계 (6분)** 📽 19 🖊 칠판 가운데 구역
```
① k-means 양자화: 시범의 모든 행동 벡터 → k개 대표 행동(군집 중심) = "행동 사전"
② Transformer(minGPT)가 관측 히스토리를 받아
   (a) 어느 군집인가?  → softmax 분류  → 봉우리 고르기(다봉성)
   (b) 중심에서 얼마나 떨어졌나? → 잔차 오프셋 회귀 → 정밀도 복원
   최종 행동 = 중심[선택된 군집] + 오프셋[선택된 군집]
```
🖊 그림: 2D 평면에 점 구름 → 동그라미 몇 개(군집) → 한 동그라미 안에서 화살표(오프셋)
> "비유: 지도에서 먼저 '어느 동네'인지 고르고(이산), 그다음 동네 안의 정확한 번지수(연속)를 찍는다."

**D-3. 휴식 퀴즈 답 (2분)** — 오프셋이 약점 ①(정밀도)을 보완한다는 연결.

**D-4. 손실 함수 (3분)** 📽 20 — 디테일, 시간 없으면 한 줄
```
L = Focal(군집 분류)  +  λ · || 오프셋[정답 군집] − 실제 잔차 ||²
                          ↑ 정답 군집의 오프셋만 학습 (다른 군집 오프셋은 건드리지 않음)
```
- focal loss = "쉬운 문제(자주 나오는 군집)의 가중치를 낮춰, 드문 군집도 잘 배우게 하는 분류 손실"
- 모델은 **모든 군집에 대해 오프셋을 한꺼번에 출력**하고, 학습 때는 정답 군집 것만, 실행 때는 뽑힌 군집 것만 씀

**D-5. 실험과 의의 (5분)** 📽 21–22
- 실험(시뮬레이션): 자율주행(CARLA, 건물 좌/우로 돌아가기), 블록 밀기(어느 블록을 어느 목표에), Franka Kitchen(7개 하위 작업의 **순서** 다봉성)
- 결과 메시지: 기존 BC(MLP, 연속 회귀)는 모드가 섞여 실패, **BeT는 여러 모드를 모두 재현** — 다양한 순서로 작업을 수행
- 의의: **"행동 이산화" 계보의 시조**. 6주차 RT-1/RT-2/OpenVLA의 "차원별 256-bin 균등 이산화"는 이 정신의 직계 후손(방식은 더 단순)
- 한계: k에 민감, 정밀 조작에서 이산화 손실, 원 논문은 조건(목표) 없는 정책 → 후속 C-BeT(목표 조건), VQ-BeT(2024, 잔차 벡터 양자화로 k-means 대체)

✅ 체크: "BeT에서 softmax는 무엇을 담당하나?" → "봉우리 고르기".

### E. 해법 2 — Diffusion Policy (1:25–1:50) 📽 23–29

**E-1. 한 문장 (3분)** 📽 23
> "지난주 예고를 회수하겠습니다. **관측을 조건으로, 미래 행동 시퀀스를 diffusion으로 생성한다.** 끝입니다."
🖊 칠판 가운데, 2주차 그림을 다시 그리고 글자만 바꾸기:
```
2주차:  노이즈 이미지 x_T  ──denoise×K──▶  이미지 x_0          조건 c = 텍스트
오늘:   노이즈 행동열 A_T  ──denoise×K──▶  행동 시퀀스 A_0     조건 c = 최근 관측(이미지 2장 + 로봇 상태)
손실:   || ε − ε_θ(A_t, t, 관측) ||²        ← 2주차 손실과 글자 하나 다르지 않음
```

**E-2. 작동 흐름: receding horizon (5분)** 📽 24
🖊
```
관측 2스텝(T_o=2) → 행동 16스텝 생성(T_p=16) → 앞 8스텝만 실행(T_a=8) → 새 관측 → 다시 생성
```
> "내비게이션이 전체 경로를 그려주지만 몇 초마다 다시 계산하는 것과 같습니다. 계획은 길게, 실행은 앞부분만."
- 왜 16개를 만들고 8개만 쓰나? → 길게 계획해야 일관성, 짧게 실행해야 반응성. (chunking 박스 효과 1·2와 연결)

**E-3. 왜 잘 되나 — 세 가지 (5분)** 📽 25
1. **다봉성**: 분포 자체를 배움 → 데모 그림 (3)
2. **시간적 일관성**: 16스텝을 한 덩어리로 생성 → chunking 내장
3. **정밀도**: 이산화 없음 → 연속 행동 그대로
4. (보너스, 3주차 연결) **학습 안정성**: 이전 방법 IBC(암묵적 정책, 에너지 모델)는 정규화 상수 때문에 음성 샘플링이 필요해 불안정했는데, DP는 **에너지의 기울기(= score)를 직접 배워** 그 문제를 피함. "3주차에 'diffusion 학습 = score 학습'이라 했던 것이 여기서 실익으로 나타납니다."

**E-4. 결과 (4분)** 📽 26 + 영상 2
- **4개 벤치마크 15개 과제**에서 기존 최고 방법 대비 **평균 46.9% 향상** (비교 대상: LSTM-GMM, IBC, BET)
- 실제 로봇: Push-T(T 블록 밀어 넣기), 머그컵 뒤집기, 소스 붓기·펴 바르기
- 영상 포인트: **사람이 블록을 치워도 다시 계획해 복구** → receding horizon의 힘

**E-5. 구조 두 가지 + 실무 팁 (4분)** 📽 27
| | CNN 기반 (1D temporal U-Net) | Transformer 기반 |
|---|---|---|
| 조건 주입 | FiLM (관측으로 채널 조율) | cross-attention |
| 추천 | 기본값, 튜닝 쉬움 | 행동이 급변하는 과제 |
- 비전 인코더: ResNet-18을 **처음부터 함께 학습**, 전역 풀링 대신 spatial softmax, BatchNorm → GroupNorm
- 위치 제어(position control)가 속도 제어보다 잘 맞음 (누적 오차에 덜 민감)

**E-6. 약점 — 2주차 걱정의 회수 (4분)** 📽 28–29
> "2주차에 '생성은 느리다, 로봇은 0.02초마다 행동을 내야 하는데?'라는 걱정을 심어 뒀죠. 그게 이 논문의 한계로 등장합니다."
- 학습 K=100 denoising → 실행 시 DDIM으로 **10스텝**, 약 0.1초 (RTX 3080)
- chunking으로 상쇄(한 번 생성으로 8스텝 실행)하지만 근본적으로 반복적
- → 3주차 flow matching 채택(π0), 12주차 효율화(RTC)의 동기
- 의의: 소규모 모방학습의 **사실상 기본 베이스라인**, Octo(6주)의 diffusion head, GR00T(8주)의 DiT head의 뿌리

✅ 체크: "DP와 2주차 이미지 diffusion의 차이는?" → "x가 행동 시퀀스, c가 관측. 수학은 같다."

### F. 해법 3 — ACT (1:50–2:10) 📽 30–36

**F-1. 배경: 하드웨어가 반이다 (3분)** 📽 30 + 영상 1
> "저자들은 알고리즘 전에 장비부터 만들었습니다. **ALOHA** — 2만 달러 이하의 저가 양팔 원격조종 장비. 사람이 작은 리더 팔 두 개를 잡고 움직이면 큰 팔로워 팔 두 개가 그대로 따라합니다. 카메라 4대, 50Hz."
- 과제: 지퍼백 열기, 건전지 끼우기, 투명 소스컵 뚜껑 열기, 벨크로 끼우기, 테이프 붙이기, 신발 신기기
- "하드웨어(ALOHA) + 알고리즘(ACT)이 세트인 논문. 후속 Mobile ALOHA, ALOHA 2로 이어짐"

**F-2. ACT = chunking이 주인공 (4분)** 📽 31
🖊
```
관측: 카메라 4대 이미지 + 관절 14개  →  Transformer  →  미래 행동 k = 100개 (50Hz에서 2초)
                                                      (한 번의 forward로, 회귀(L1))
```
> "이름 그대로 Action Chunking with Transformers. 100개를 한 번에 회귀로 뽑습니다. diffusion처럼 반복하지 않으니 빠릅니다."

**F-3. 장치 1: CVAE (6분)** 📽 32–33
- VAE 5분 보충 (📽 32):
> "VAE는 데이터를 짧은 요약 벡터 z로 압축했다가 z로부터 다시 복원하게 학습하는 오토인코더의 확률 버전입니다. 여기서는 **z = 시범의 스타일 요약**이라고만 이해하면 충분합니다."
- ACT에서의 역할 (📽 33) 🖊
```
[훈련]  인코더: (실제 시범 행동 100개 + 관절) → z (시범 스타일: "빠르게/조심스럽게/왼쪽부터")
        디코더: (이미지 + 관절 + z) → 행동 100개 복원        손실 = L1 복원 + β·KL
[실행]  인코더 없음. z = 0 (평균 스타일) 고정 → "가장 표준적인 스타일"로 움직임
```
> "같은 장면에서 시범이 제각각인 것(다봉성 + 손떨림)을 z가 흡수해 줍니다. z가 스타일을 떠맡으니 디코더는 '평균 내기'를 할 필요가 없습니다."
- 흥미로운 ablation(말로): **사람이 모은 데이터**에서는 CVAE를 빼면 성능이 크게 떨어지지만, **스크립트로 생성한(스타일이 일정한) 데이터**에서는 차이가 거의 없음 → CVAE가 정말 '사람의 들쭉날쭉함'을 흡수한다는 증거

**F-4. 장치 2: Temporal Ensembling (4분)** 📽 34
🖊
```
매 스텝 새 chunk 예측 → 현재 시점 t에 대해 과거 여러 chunk가 낸 예측들이 겹침
실행 행동 = Σ w_i · 예측_i / Σ w_i,   w_i = exp(−m · i)   (i=0이 가장 오래된 예측)
```
> "계획이 급변하지 않게 하는 완충 장치. m이 작을수록 새 관측을 빨리 반영합니다."
- 대비: DP는 "8개 실행 후 새로" (끊어서 실행), ACT는 "매 스텝 예측 + 겹친 것 평균" (부드럽게)

**F-5. 결과 (3분)** 📽 35
- 과제당 시범 **50개(약 10분 분량)**로 정밀 양팔 과제 **80~90%대 성공** (건전지 끼우기, 컵 뚜껑 열기 등). 가장 어려운 벨크로 끼우기는 20%대
- 비교 대상(BC-ConvMLP, BeT, RT-1, VINN)은 실제 과제 대부분에서 거의 실패
- chunk 크기 ablation: k=1에서 k를 키울수록 성공률이 크게 오름 → **"chunking이 성능의 핵심"**
> "충격 포인트: 데이터 50개 + 회귀로도, chunking과 스타일 처리만 잘하면 정밀 조작이 된다."

✅ 체크: "ACT가 실행할 때 z에 무엇을 넣나?" → "0 (평균)".
